# TrackIn1# TrackIn – Attendance Decision Navigator

**Don't just track attendance. Plan every absence.**

TrackIn is a timetable-aware attendance planner for SRM Trichy (Odd Sem 2026-27). College portals show attendance history; TrackIn helps students plan attendance decisions until the semester ends (29 Nov 2026).

## Features
- Section-wise timetables: II BME, II ECE-DS A, III BME, III ECE-A/B/DS, IV ECE-A/B
- Subject-wise attended / conducted input with auto percentage
- Classes needed to finish at 75% / 80% / 90%, and maximum safe absences
- Projected attendance on any future date
- Irreversible "Mathematical Recovery Alert" when the target cannot be reached
- Point-of-no-return date per subject
- 14-day daily plan (Must attend / Attend / Flexible) with copy-to-WhatsApp
- LeaveSafe Planner with earliest safe leave window suggestion
- "If I miss N more classes" slider, risk sorting, auto-save on device

## Run
No install needed. Open `index.html` in any browser.

## Tech
Plain HTML, CSS and JavaScript. No backend or database.
